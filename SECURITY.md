# Security and privacy

SkillParcel v1 accepts intentionally prepared local synthetic fixtures. It is not a safe execution environment for arbitrary Internet skills. Unknown frontmatter, dynamic shell injection, links outside a case and symlinks are refused. Shell/network/write tools and hooks are unnecessary and disabled. The separately installed native vendor binary is verified by Mach-O architecture, vendor signature, version and tested SHA-256 before invocation; a stand-in is not a native test.

All input handling is bounded. Native process spawning uses argv arrays and `shell: false`. Loopback listens on `127.0.0.1`, selects a free OS port, requires a per-run synthetic credential, and never proxies or redirects. Unknown blocks, stale inputs, ambiguous stages, failed Read and zero checks cannot become passing measurements. Original files and author goldens are never updated by a run. Output files use exclusive writes and an output reservation. Two sessions share no generated config/session/port/PID.

The child receives an environment allowlist and an owned config directory; HOME is not changed. Bare mode avoids real OAuth and Keychain reads in the tested version. Managed policies cannot be universally disabled by settings flags; detected policy presence blocks this adapter. No global settings, security configuration, login, or unrelated processes are changed. Nonessential traffic switches are applied, but no OS egress confinement is claimed.

The default public serializer does not expose raw captures, system prompts, headers, stdout or environments. Reports intentionally display author-supplied text as text, with safe JSON embedding, control-character display escapes and no network connections. A fixture author remains responsible for excluding confidential text from their own input fragments. Explicit private capture is opt-in, uses mode 0600, may retain third-party instructions/private metadata, and must be deleted after local diagnosis. Do not attach it to issues or CI artifacts.

For a security report, share a minimal original synthetic reproducer with the affected version, stage and reason. Do not include credentials, real profiles, vendor system text or private capture. Use GitHub's private vulnerability reporting if enabled; otherwise contact the maintainer through the profile's available private channel. No unsolicited message is sent by this tool.
