# Contributing

Use Node 24 LTS. Run `npm ci`, typecheck, lint, build, unit tests, report tests and package consumer checks. The portable suite needs no Claude account. Browser dependencies can be installed with `npx playwright install chromium`.

Define original synthetic author contracts before capturing native output. Never update a golden from observed text simply to make a test pass. Explain intentional substitution, escapes and normalization. Add meaningful negative controls. Keep body loading, native tool execution and transmitted Read results separate and correlate by exact IDs.

Any expanded native coverage requires signed binary identity, documentation/help verification, isolated provider capture, three stable runs, Read correlation, an installed-package consumer check and a dated report tied to a commit. Unit stand-ins cannot support native claims. New protocol blocks are unsupported until measured.

Keep credentials, private profiles, raw HTTP, vendor instructions and arbitrary downloaded skill code out of contributions. MIT license applies to original code and synthetic fixtures. Competitor modules were inspected, not copied. P2 integrations should add a reviewed adapter/contract boundary rather than a speculative plugin framework.
