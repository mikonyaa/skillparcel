# Synthetic captured native demo

[demo.cast](demo.cast) is a real 25-second asciicast v2 terminal recording from an installed local release candidate, with its date and Claude Code 2.1.280 shown in the first frame. It contains the original dollar-digit skill, actual installed CLI stdout, expected/transmitted fragments and the forced native Read evidence. Only original synthetic content is included. The final screen is held to reach 25 seconds; no vendor bug or terminal output is drawn in.

Use an asciicast v2 compatible terminal player. [Metadata](demo-metadata.json) gives the duration and capture origin. The pre-commit recording has `sourceCommit: null`; the release attaches a separate recording made from the exact CI archive on the tagged source commit.

The [static report](../../examples/report.html) offers a quick offline view. It is recorded evidence and does not verify the machine opening it.
