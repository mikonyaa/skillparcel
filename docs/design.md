# Report design

Direction: a quiet transmission lab notebook. The reader compares an author contract to the actual native fragment and follows the source → loader → endpoint → forced Read chain. Context fit and traceability take priority over decoration. Design feasibility score: impact 3 + fit 5 + feasibility 4 + performance 4 − consistency risk 2 = 14.

Warm paper, dark ink, one green accent, explicit text for violation/error/unsupported states. Local Georgia for the document heading and platform monospace for transport fragments; no external fonts. A simple stage rail and a dense case table give the report its character. Two comparison columns collapse to one on mobile. Code scrolls within its own container. Every diff has `+`/`-` text in addition to color. No animation, gradients or decorative cards.

The report uses semantic headings/table/buttons, keyboard focus, labelled filters, expandable evidence, safe text nodes, offline CSP and clipboard fallback. Display escaping of controls is explicitly separate from byte/text comparison. Screenshot and browser checks cover 1440, 1024 and 390 px; see QA evidence.
