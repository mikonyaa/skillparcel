# Engineering baseline — inspected 2026-10-12

This is a bounded source review, not a market survey or proof of unique functionality. README, license and directly relevant modules were read from the pinned snapshots below. No competitor implementation was copied or executed.

| Existing capability | SkillParcel addition | Inspected source / measured evidence |
| --- | --- | --- |
| [agent-bundle](https://github.com/scriptedalchemy/agent-bundle/tree/bf98f04f4620b8ff416f040245c6b7a007b7a677), Apache-2.0: multi-host plugin compilation, native validation, host contracts and native stream/process evidence. Significant overlap in native conformance. | Narrow author text contracts against actual decoded outbound Messages blocks before inference; distinct body and forced Read transmission. No claim that native testing itself is new. | README, `packages/agent-bundle/src/host-contracts/native-claude-contract.ts`, `src/eval/claude-process.ts`, `src/eval/claude-harness.ts`: CLI process/stream integration inspected. This snapshot's native environment helper removes some provider variables while relying on subscription mode. SkillParcel's separately verified loopback fixture reports show text/ID correlation. |
| [vibe-agent-toolkit](https://github.com/jdutton/vibe-agent-toolkit/tree/6e14d0f055d1b0b66f587c5a24cc8566f02581cf), MIT: agent/skill packaging, resource registry, relative link validation, copying contained resources and dependency graphs. | A valid on-disk reference is distinguished from native execution and its actual transmitted content. | README, `packages/resources/src/link-validator.ts`, `packages/resource-compiler/src/utils/copy-resources.ts`; static path/link/resource capabilities observed in source. SkillParcel's withheld/read pair gives actual stage evidence. |
| [skillship](https://github.com/shivdeepak/skillship/tree/d4f96799b264875ec5b154940a4cd49266e2623e), MIT: per-surface validation, `.skill` packaging, scaffolding and installation orchestration. | Post-loader literal-contract capture, rather than certification of a packaged file's model-facing text. | README, `src/commands/package.ts`, LICENSE; package flow calls source loading/profile validation/ZIP packing. No runtime loader claim is inferred from packaging. |
| [agent-skill-eval](https://github.com/tardigrde/agent-skill-eval/tree/59de161f657b82bfaf8f6abe83dfff38552deb21), MIT: real CLI behavior evaluation, with/without skills, workspace/state deltas, repeated runs and assertions. | Deterministic pre-inference endpoint observation with an inert synthetic provider; author text and reference transmission contracts. Its Claude command uses real CLI JSON output and skip-permissions; SkillParcel instead restricts tools and uses ordinary scoped permissions. |
